# 0.2.0 — 2026-10-10

- Standalone repository and package, Docker Compose and bundled Chromium.
- Generic declarative make/model profile with variant matching for NL/DE.
- Configuration validation and immutable database binding to the search scope.
- Portable writer lock and separate daemon lock.
- History and evidence retention, with merging of verified identities.
- Commands for search, diagnostics, coverage, quality, catalog, export and backup.
- Persistent scheduler, heartbeat, graceful shutdown and backoff after 403/429.
- Built-in English analytics: editorial PNG/PDF, large panels, CSV, JSON and verifiable SQLite snapshots.
- Exclude personal insurance tools, delivery programs and host installers.

Based on native adapters and history from an earlier private research collector.
