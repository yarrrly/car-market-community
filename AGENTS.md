# Car Market

Standalone Python 3.12 package. Public operator entrypoint: `car_market.portable`.
Use English for code, identifiers, comments and user documentation.
Keep captured source-language text unchanged in evidence fixtures.

- Run `uv sync --frozen --group dev --extra browser --extra reports` and `uv run --no-sync pytest tests -q`.
- Validate the portable workflow against both retained native fixtures and fault injection.
- Do not edit installed runtime copies or existing user databases.
- One daemon and one writer per workspace. Selectors and countries are immutable bindings.
- Retain source timestamps, response SHA-256 and publication identity. Never manufacture facts.
- Missing/blocked/partial responses cannot mean sold or complete market coverage.
- Exact own VIN/NL plate or verified publisher evidence may merge vehicles. Similarity cannot.
- Do not bypass login/CAPTCHA or send messages. Accounts and cookies remain external.
- Historical BMW/Mercedes adapters exist for regression compatibility. New public adapters
  must declare country, host, pagination and observed native payload contracts in configuration.py.
- Data, exports, browser profiles and secrets must never be committed.
- Keep only source, required assets, documented examples and regression evidence in Git.
- Packaging must retain the complete regression fixture set, including gzip captures.
- No AI attribution in commits or repository prose.
